A webcam that notices when you stop studying

FocusGuard AI watches the desk through an ordinary webcam. If you pick up your phone, doze off or walk away, it plays a sound of your choice, shows a message and logs it for later.

What it detects

Five situations, each with its own response. Sounds and messages are all editable in the web app.

SituationHow it is recognisedResponse
Using mobileYOLO finds a phone in the frame for about 2 secondsSound, popup, screenshot
SleepingEyes stay closed (eye aspect ratio below threshold)Sound, popup, screenshot
Not presentNo person and no face in view for about 8 secondsBeep and popup
StudyingHead tilted down with eyes openNone, logged as focused time
Looking at screenFace visible and facing forwardNone, logged as focused time

How it works

Two pretrained models, a few simple rules and a web app on top.

  1. Capture. A background thread reads the newest 640 × 480 frame so the video never lags behind.
  2. Detect. YOLO11n finds phones and people. MediaPipe Face Landmarker finds the eyes, nose, forehead and chin.
  3. Measure. Eye aspect ratio tells open eyes from closed ones. A nose-to-chin ratio tells head-down from head-forward.
  4. Decide. A state must last a few seconds before it counts, so blinks and missed frames do not set off alarms.
  5. Respond. Play the chosen sound, show a popup, save a screenshot and write the event to a CSV log.
  6. Review. The Streamlit app shows live video, a focus score, charts by hour and day, and a daily goal.

Features

  • Live camera view inside the browser
  • Different sound, loop mode and message for each alert
  • Upload your own mp3, wav or ogg files
  • Calibration wizard that sets thresholds for your face and camera angle
  • Pomodoro timer that pauses alerts during breaks
  • Daily study goal with progress bar
  • CSV log export and printable HTML report
  • Privacy mode that hides the video while detection continues
  • Everything runs on your own computer, on the CPU
  • Screenshot gallery with delete buttons

Run it

Needs Python 3 and a webcam. Tested on Windows.

git clone https://github.com/Raman-yadav17/FocusGuard-AI.git
cd FocusGuard-AI
pip install -r requirement.txt
python -m streamlit run app.py

Put yolo11n.pt in the models folder. The face model downloads itself on the first run. Press Start in the sidebar, then open the Calibrate tab once.
